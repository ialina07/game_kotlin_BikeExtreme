# Велоэкстрим (BikeExtreme) 🚴🏻

Система для администрирования настольной игры «Велоэкстрим».

## О проекте

Это приложение для администрирования партий.  
Ведущий записывает ходы игроков, система проверяет их корректность по правилам, сохраняет историю и считает статистику.

### Игра «Велоэкстрим»

Гонка на велосипедах с динамической погодой.  
Игроки управляют ресурсами: энергия, состояние велосипеда, вода.  
Побеждает тот, кто первым достигнет 50-й клетки.

## Функции системы

- Запись ходов игроков
- Валидация ходов по правилам игры
- Хранение истории партий
- Расчёт статистики и рейтингов игроков
- Повтор (replay) любой партии

## Запуск

### Запуск приложения

```bash
./gradlew run
```

### Запуск всех тестов
```bash
./gradlew test
```

### Запуск конкретного теста
```bash
./gradlew test --tests "com.bikeextreme.weather.WeatherTest"
```

### Запуск интеграционных тестов
```bash
./gradlew test --tests "com.bikeextreme.integration.IntegrationTests"
```

### Запуск системных тестов
```bash
./gradlew test --tests "com.bikeextreme.system.SystemTests"
```
