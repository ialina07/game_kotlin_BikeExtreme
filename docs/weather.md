# Погода (Weather)

Погода определяется первым кубиком (dice1).

## Таблица погоды

| dice1 | Погода | Эффект |
|-------|--------|--------|
| 1 | HeatWeather (Жара) | -1 вода (если воды нет -> -1 энергия) |
| 2 | RainWeather (Дождь) | -1 состояние |
| 3-4 | NormalWeather (Обычно) | без изменений |
| 5 | TailwindWeather (Попутный ветер) | +2 клетки к движению |
| 6 | StormWeather (Шторм) | -2 состояние |

## Примечания

- Попутный ветер даёт бонус к движению, который суммируется с бонусами от событий
- Жара тратит воду, если воды нет - тратит энергию
